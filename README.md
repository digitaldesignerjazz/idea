# idea

> A living repository for capturing, refining, developing, and tracking ideas across technology, business, creative, and research domains.

## 🚀 Purpose

This repository serves as a central, version-controlled space to:
- Capture raw ideas quickly
- Refine and expand promising concepts
- Track status and evolution of ideas
- Maintain historical context and decision rationale
- Collaborate on idea development

## 📂 How to Use This Repository

### Adding a New Idea
1. Copy the template from `templates/idea-template.md`
2. Create a new file in `ideas/` using kebab-case naming (e.g. `ideas/my-new-concept.md`)
3. Fill in the template
4. Commit with a clear message: `feat(idea): add [short name]`

### Idea Lifecycle
- **Raw** → Initial capture
- **Exploring** → Research & early prototyping
- **Active** → In development or testing
- **Mature** → Stable / ready for integration
- **Archived** → Completed, rejected, or superseded (move to `archive/`)
